# ИИ-аналитик

Бесплатное веб-приложение для анализа CSV-файлов и скриншотов с помощью Gemini Flash.

Открыть: загрузите `index.html` в браузере или используйте опубликованную версию на GitHub Pages.

## Возможности
- Загрузка CSV (drag&drop, выбор файла, Ctrl+V для скриншотов)
- Автоматические графики (линия / столбцы / круговая) на Chart.js
- Таблица данных (первые 50 строк)
- AI-анализ через Gemini 1.5 Flash (текст + изображения)
- Пресеты запросов: полный анализ, аномалии, тренды, рекомендации, описание скрина
- PWA: устанавливается как приложение, работает офлайн (кроме AI-запросов)

## Настройка
1. Получите бесплатный ключ Gemini: https://aistudio.google.com/app/apikey
2. Откройте приложение, нажмите «API-ключ», вставьте ключ — он хранится только в `localStorage` вашего браузера.

## Деплой
Файлы статические — просто загрузите `index.html`, `manifest.json`, `sw.js` в репозиторий и включите GitHub Pages (Settings → Pages → Source: main / root).

Подробное техническое описание — в [PRD.md](PRD.md).
