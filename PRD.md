# PRD — ИИ-аналитик (AI Analyst MVP)

**Версия:** 1.0  
**Дата:** июнь 2026  
**Статус:** MVP  

---

## 1. Обзор продукта

**ИИ-аналитик** — бесплатное веб-приложение для личного использования. Позволяет загружать CSV-файлы и скриншоты, автоматически строить графики и получать текстовый AI-анализ через Gemini Flash.

Работает в любом браузере, публикуется на GitHub Pages, не требует сервера и платных сервисов.

---

## 2. Проблема

Для анализа данных обычно нужны:
- платные инструменты (Power BI, Tableau),
- навыки программирования (Python, R),
- или сложная настройка окружения.

Пользователь хочет простой инструмент: загрузил → увидел графики → получил выводы.

---

## 3. Целевая аудитория

- Аналитики, менеджеры, предприниматели без технического бэкграунда
- Работа с любого ПК — офис, дом, командировка
- Использование в Telegram Web и браузере без установки

---

## 4. Цели и метрики

| Цель | Метрика |
|------|---------|
| Быстрый старт | Первый анализ за < 2 минут |

## 5. Возможности MVP

### 5.1 Загрузка данных
- **CSV** — автоматический парсинг, определение типов колонок (число / дата / текст)
- **Изображения** — PNG, JPG, WEBP (скриншоты дашбордов, графиков, документов)
- **Текстовые файлы** — TXT, JSON, MD (передаются в контекст AI)
- **Ctrl+V** — вставка скрина из буфера обмена
- **Drag & Drop** — перетаскивание на любую область страницы

### 5.2 Автоматические графики (без AI)
- Линейный график по числовым колонкам
- Столбчатая диаграмма
- Круговая / кольцевая диаграмма по категориям
- Переключение типа графика в один клик
- Статистика: min, max, среднее
- Выбор колонок для отображения

### 5.3 Таблица данных
- Первые 50 строк с возможностью прокрутки
- Подсветка заголовков
- Адаптивная ширина колонок

### 5.4 AI-анализ (Gemini Flash)
- Текстовые выводы по загруженным данным
- Анализ изображений и скриншотов
- Структурированный ответ: Executive Summary → Инсайты → Анализ → Риски → Рекомендации
- Быстрые запросы (пресеты):
  - Полный анализ
  - Аномалии и выбросы
  - Тренды и динамика
  - Рекомендации
  - Описать скрин

### 5.5 AI-провайдер
- **Gemini 1.5 Flash** (Google AI Studio)
- Бесплатный тариф: 1 500 запросов/день
- Ключ хранится в `localStorage` браузера
- Ключ не передаётся на сторонние серверы

### 5.6 Интерфейс
- Адаптивный дизайн (ПК, планшет, Telegram Web)
- Dark mode — автоматически по системным настройкам
- PWA — устанавливается как приложение на телефон и ПК
- Офлайн-шелл через Service Worker

## 6. Вне скоупа MVP

| Функция | Причина исключения |
|---|---|
| Авторизация / аккаунты | Личный инструмент, не нужна |
| База данных на сервере | GitHub Pages — статика |
| Поддержка Excel (.xlsx) | Требует тяжёлой библиотеки |
| Совместная работа | Вне MVP |
| История сессий | Вне MVP |
| Экспорт PDF | Вне MVP |

---

## 7. Технический стек

| Слой | Решение |
|---|---|
| Хостинг | GitHub Pages (бесплатно) |
| Frontend | Vanilla HTML + CSS + JS (без фреймворков) |
| Графики | Chart.js 4.x |
| Парсинг CSV | PapaParse 5.x |
| Иконки | Tabler Icons (CDN) |
| AI | Google Gemini 1.5 Flash API |
| PWA | Service Worker + Web Manifest |
| Хранилище | localStorage (ключ API) |

---

## 8. Архитектура

```
[Пользователь]
     │
     ▼
[GitHub Pages]  ←── index.html / manifest.json / sw.js
     │
     ├── Файлы/скрины  →  FileReader API  →  localStorage / переменные
     │
     ├── CSV  →  PapaParse  →  Chart.js  →  Графики
     │
     └── Prompt  →  Gemini API  →  Markdown  →  AI-карточка
```

Всё выполняется на стороне клиента. Сервера нет.

---

## 9. UX-флоу

```
1. Открыть приложение
2. Ввести Gemini API ключ (один раз)
3. Загрузить CSV или скрин (drag&drop / кнопка / Ctrl+V)
4. Увидеть автоматические графики и таблицу
5. Выбрать пресет или написать свой вопрос
6. Нажать «Анализировать»
7. Получить структурированный AI-анализ
```

---

## 10. Деплой

### GitHub Pages (рекомендуется)
1. Создать новый репозиторий
2. Загрузить 4 файла: `index.html`, `manifest.json`, `sw.js`, `README.md`
3. Settings → Pages → Source: **main / root**
4. Приложение доступно по адресу: `https://[username].github.io/[repo]`

### Локально
Открыть `index.html` в браузере — работает без сервера.

---

## 11. Получение Gemini API ключа

1. Перейти на [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
2. Войти через Google аккаунт
3. Нажать «Create API key»
4. Скопировать ключ и вставить в приложение

**Стоимость:** $0 (бесплатный тариф — 1 500 запросов/день, карта не нужна)

## 12. Риски и ограничения

| Риск | Влияние | Митигация |
|---|---|---|
| Лимит Gemini (1 500/день) | Средний | Достаточно для личного использования |
| Изменение условий Google | Средний | Можно переключить на другой бесплатный провайдер |
| Большие CSV (>10 MB) | Средний | Отправляем первые 80 строк в контекст AI |
| Безопасность ключа | Низкий | Ключ только в localStorage, не в коде |
| Нет поддержки .xlsx | Низкий | Экспорт в CSV перед загрузкой |
